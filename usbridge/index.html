Finutia USBridge

One tool.
Every device.

USBridge connects a USB tool plugged into one Windows device — an MDI 2, a CarDAQ, a pass-thru — to another device on your network, where the software that needs it runs. It grades the link before a job starts, holds the tool through a knocked cable, and shows every device who has it.

How it works

Two installs, then one button.

The same app goes on every device. At install you say what each one does: shares the tools plugged into it, or receives tools from the others.

01

Where the tool plugs in

This device shares its tools. USBridge lists what is plugged in, and which device each tool is connected to.

02

Where the software runs

This device receives tools. Any Windows device on your network, or reached over Tailscale when it is not.

03

Connect, work, release

Choose the device and press Connect: the tool appears there as if it were plugged in. Release it from either side when the job is done.

Built for jobs that must not drop

A flash is not the moment to find out the link is bad.

LINK

A grade for every device

Each device is measured every second — latency, jitter and loss — and graded A to C. A speed test shows what the link carries.

PROGRAMMING

Programming Mode

Turn it on for a flash or a coding job: the link is watched closely, the device stays awake, and nobody can take the device mid-job.

READINESS

A check before you start

A readiness checklist runs before Programming Mode: the tool, the link and the settings that break long jobs.

CABLES

A knocked cable comes back

A tool unplugged for a moment is held for its device and reconnects on its own when it returns.

AWAY

Held while you step away

If the device sharing a tool sleeps or leaves, the other device keeps the tool for as long as you set, so a walk to the parts counter does not end the job.

RECORDS

A record of every job

Which tool, which device, how long, and the link through it — kept on both sides, with a note, and exported when support asks.

Updates

Every device stays current.

No one has to go round the shop installing anything. Each device looks for a new release once a day. It installs only after nothing has been connected for ten minutes, and never in Programming Mode. The window closes for a moment and comes back on the new version. Every release is signed by Finutia and checked before it runs.

Before you install

What each device needs.

The installer checks for these and says what is missing. It does not install them for you.

  • Windows 10 or 11, 64-bitOn every device.
  • An administrator, onceUSBridge runs as a Windows service, so installing it asks for one.
  • On a device that shares its toolsusbipd-win, free and open source.
  • On a device that receives toolsusbip-win2 0.9.8.1 or newer, free, open source and signed by Microsoft.
  • A network between themThe same shop network, or Tailscale when a device is somewhere else.
  • One device per tool at a timeSeveral devices can share and receive; each tool goes to one device until it is released.
