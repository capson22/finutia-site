Auto, Manual, and Bypass approval modes.

Approval modes control when Finutia AI pauses for a press before an outside action. They do not change the facts available to the assistant or make a failed provider action succeed.

Auto

Finutia AI uses the rules you set, the facts it knows, and its judgment to decide when an action should pause for approval. This is the default mode.

Manual

Outside actions pause for your approval unless you have explicitly allowed that particular tool to proceed without asking each time.

Bypass

Work proceeds without an approval prompt. Product guardrails, account permissions, and provider requirements still apply.

Examples

  • Finding an invoice or reading a calendar is different from sending a message or changing a record.
  • In Auto, the applicable rules and known facts help decide whether Finutia AI pauses.
  • In Manual, a customer-facing action normally waits for your press unless its specific tool has been allowed.
  • In Bypass, the action can proceed without the approval card, but it still appears in Finutia AI's activity records.
You can change the mode later.

The right setting may be different while testing a new connector than it is after you understand how that tool behaves.

Connected MCP tools

An MCP server can offer tools Finutia AI did not write. Finutia AI keeps the server's identity attached to those tools and routes their calls through the same approval system. Review the server and its capabilities before allowing a foreign tool to run without asking.

Start with the level of review that fits your comfort.

You can keep hands-on control while learning the system and adjust it as your rules become clearer.
