Beyond the built-ins

Connect compatible tools through MCP.

MCP is a standard way for other software to offer tools to an AI assistant. Add a compatible server and Finutia discovers what it offers, keeps a pinned list of those tools, and makes them available in your conversations.

Finutia identifies which server provided each tool, protects the server address and sign-in details, and applies your approval settings before outside work runs. If a tool changes or disappears, Finutia can show you what changed instead of silently trusting a different set of capabilities.
